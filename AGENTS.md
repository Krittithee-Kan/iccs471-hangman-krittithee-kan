# Instructions for this repository

- First, read README.md before you write code.
- You must only make change in the three requirement inside README.md. Do not do other things.
- Use Python 3.10 or up. Use only standard library. You should use csv to read words.csv. For test, use pytest.
- Put the game rule in game.py. Rule is like word length difficulty, guess, life, win or lose and check input. Do not use input() or print() in game.py. Put all user play things in main.py.
- When you start game, you must put the secret word, meaning and life inside it. So the test is not random and not need words.csv.
- Put your test in the file tests/test_game.py.
- You can run test by typing python -m pytest.
- If test is fail, do not change expected result just to make it pass. If you have problem or not agree, tell me for review.
- Finally, leave the requirement, expected result, note and final judge empty. The student will write it.
